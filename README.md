# SmartCampus Cloud

A Student Campus Management System built using Python Flask and SQLite.

## Project Overview

SmartCampus Cloud is a web-based campus management application designed to simplify academic and administrative activities.

## Features

- Student Registration and Login
- Admin Dashboard
- Student Dashboard
- Course Management
- Lesson Management
- Course Enrollment
- Campus Events
- Document Upload and Download
- Notification Management
- Student Profile Management

## Technology Stack

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript
- Git and GitHub

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sinan592/SmartCampus-Cloud.git
   ```

2. Open the project folder:

   ```bash
   cd SmartCampus-Cloud
   ```

3. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

4. Activate the virtual environment on Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Run the application:

   ```bash
   python app.py
   ```

7. Open in your browser:

   ```text
   http://127.0.0.1:5000
   ```
